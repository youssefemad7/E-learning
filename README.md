# E-Learning Platform

A full-stack online learning platform designed to connect students and instructors through an intuitive learning experience.

The platform enables students to explore courses, enroll in learning content, and track their progress, while instructors can create and manage their own courses.

**Project Status:** Under Development

---

## Overview

E-Learning is a full-stack web application inspired by modern online learning platforms. It is being developed with a focus on clean architecture, secure authentication, and scalable backend design.

### Planned Features

- User authentication and authorization
- Role-based access control (Student, Instructor, Admin)
- Course creation and management
- Course categories and organization
- Course enrollment and learning progress tracking
- Instructor course and student management
- Administrative management

## Tech Stack

| Layer          | Technologies                       |
| -------------- | ---------------------------------- |
| Frontend       | React, TypeScript, Vite            |
| Backend        | NestJS, TypeScript                 |
| Database       | MongoDB, Mongoose                  |
| Authentication | JWT, Passport.js, bcrypt           |
| Validation     | class-validator, class-transformer |
